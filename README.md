# SWYNEX Model Improvement

## Project Overview
This project focuses on improving a Machine Learning model using hyperparameter tuning and cross-validation. The Breast Cancer Wisconsin dataset from Scikit-learn is used to compare baseline and optimized Logistic Regression models.

## Objectives
- Build a baseline Logistic Regression model.
- Apply GridSearchCV for hyperparameter tuning.
- Use 5-fold stratified cross-validation.
- Evaluate and compare model performance using classification metrics.
- Analyze the effect of tuning on model performance.

## Dataset
The project uses the Breast Cancer Wisconsin dataset available through Scikit-learn.

## Tools and Technologies
- Python
- Google Colab / Jupyter Notebook
- Scikit-learn
- Pandas and NumPy
- Matplotlib and Seaborn

## Methodology
1. Load and inspect the dataset.
2. Split the data into training and testing sets.
3. Train a baseline Logistic Regression model.
4. Perform hyperparameter tuning using GridSearchCV.
5. Evaluate the tuned model.
6. Compare baseline and tuned model metrics.

## Files
- `SWYNEX_Model_Improvement.ipynb` — complete experiment and analysis.
- `model_improvement_comparison.csv` — comparison of model performance.

## Results
The notebook reports the selected hyperparameters and compares baseline and tuned model performance using accuracy, precision, recall, F1-score, and ROC-AUC.

Refer to the notebook and CSV for the actual results.

## Conclusion
This project demonstrates the use of cross-validation and hyperparameter tuning to evaluate whether model performance can be improved systematically.
